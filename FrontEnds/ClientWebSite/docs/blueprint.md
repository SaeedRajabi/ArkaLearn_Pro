# **App Name**: ArkaLearn Pro

## Core Features:

- Multi-Language & Adaptive UI: Supports both Persian (RTL, Wazir font) and English (LTR, specified font) with automatic layout and font switching based on user preference.
- Secure User Authentication & Profile Management: User registration, login, and a personal profile dashboard to manage settings, security, favorites, and purchased courses/seminars.
- Dynamic Course & Article Catalog: Browse and view online courses and articles, each with descriptions, introductory videos/photos, categories, and tags. Supports both paid and free content viewing for unauthenticated users.
- Streamlined Course & Seminar Enrollment: Authenticated users can register for free courses/seminars or proceed with payment for premium content, receiving access to materials or online event links.
- Interactive Content Engagement: Allows logged-in users to leave comments and provide ratings for courses and articles, fostering community interaction.
- AI-Powered Learning Path & Recommendation Tool: Utilizes an AI tool to suggest personalized learning paths or relevant courses/articles based on user browsing history, skills, and course interactions.
- Modern Event Calendar & Seminar Access: Displays upcoming seminars, including event details, and provides registered users with direct access links to their online sessions.

## Style Guidelines:

- Primary color: Deep Indigo (#3D2999) to convey professionalism and depth, suitable for a light theme and adaptable for a dark theme.
- Background color: Very Light Gray-Blue (#F4F4F5) providing a clean, spacious canvas, hinting at the primary hue.
- Accent color: Vibrant Sky Blue (#61D1F5) for calls-to-action, highlights, and interactive elements, offering a cool contrast.
- For Persian text, the 'Wazir' sans-serif font will be used for both headlines and body. For English text, the 'Inter' sans-serif font will be used for all content.
- Note: currently only Google Fonts are supported.
- Modern, clean, and minimalist vector-based icons that align with the 'ArkaSoftware' brand and educational themes.
- Adaptive and responsive layouts for seamless experience across devices. Supports both Right-to-Left (RTL) and Left-to-Right (LTR) content direction based on the selected language, with elegant transitions.
- Subtle yet beautiful modern animations for page transitions, interactive elements (buttons, hover states), and content loading to enhance user engagement and visual flow.
